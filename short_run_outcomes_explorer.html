Two key points on the MC curve

Break-even point
The point where MC crosses ATC at ATC's minimum. If price equals this level, the firm earns zero economic profit.
Shutdown point
The point where MC crosses AVC at AVC's minimum. If price falls below this level, the firm should stop producing in the short run.
